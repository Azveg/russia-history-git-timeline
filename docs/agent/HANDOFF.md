## Последние решённые задачи

### 2026-11-21 · Codex · Тип списка модулей для каждого человека
- У генератора индекса явно задан тип пары: ключ человека и массив путей. Устранён TS2322 на этапе `tsc --noEmit`.

### 2026-11-21 · Codex · Восстановление lockfile перед проверкой CI
- Шаг установки сохраняет исходный файл до получения контрольных сумм и восстанавливает его после аудита либо при ошибке. Проверка журнала снова видит фактические изменения проекта.

### 2026-11-21 · Codex · Исправления по замечаниям P1
- Исправлены выбор веток, ссылки на годы, региональный фильтр, навигация, вкладки и классификация. Согласованы обнаружение модулей и SEO, добавлена приоритетная загрузка по ссылкам, устранено повторное сканирование войн. Pages и CI используют закреплённые действия и проверку зависимостей перед сборкой.

### 2026-11-21 · Codex · Исправление полноты и повтора загрузки
- Полнота зависит от полученных модулей. Интерфейс сохраняет доступный срез, показывает ошибку или предупреждение и позволяет повторить недостающие запросы. Добавлены регрессии на реальных данных.
